DIMAH ORDERS

A smarter way to manage business orders.

DIMAH ORDERS is a modern business order management platform designed to help fashion brands, clothing vendors and small businesses organize customer orders, track payments and manage daily operations from one dashboard.

✨ Features

* Dashboard: View total orders, pending orders, completed orders and revenue.
* Order Management: Create and track customer orders.
* Customer Management: Keep customer information organized.
* Payment Tracking: Monitor payments and outstanding balances.
* Order Status: Track orders from pending to completion.
* Search & Filtering: Quickly find specific orders.
* Responsive Design: Designed for desktop, tablets and mobile devices.

🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start exploring the dashboard.

No additional installation is required for the current prototype.

💾 Data Storage

This initial version uses browser Local Storage to save order information.

Data is stored locally in the browser and is not yet synchronized between users or devices.
